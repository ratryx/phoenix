# Regras do Projeto

## Fluxo obrigatório
Nunca escreva código diretamente. Sempre siga estas etapas na ordem:

1. ESPECIFICAÇÃO: Descreva o que será construído, os requisitos e o comportamento esperado. Aguarde aprovação.
2. PLANO TÉCNICO: Defina a stack, arquitetura e tarefas. Aguarde aprovação.
3. IMPLEMENTAÇÃO: Escreva o código seguindo exatamente a spec e o plano aprovados.
4. VALIDAÇÃO: Revise o que foi feito comparando com a spec original. Liste o que passou e o que não passou.

## Regras gerais
- Sempre pergunte se tiver dúvida antes de assumir algo.
- Nunca pule etapas mesmo que o usuário peça pressa.
- Documente cada decisão técnica com o motivo.
